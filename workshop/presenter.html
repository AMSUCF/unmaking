Act I · Passages · Twine

AnastasiaPaper · 25 min · act1-twine.html

They leave with: a paper prototype and a branching Harlowe story that uses at least one choice that counts.

Before

  • Index cards, string or yarn, tape, markers on every table.
  • twinery.org loads on the room Wi-Fi. Have the desktop app as a fallback.
  • Open files/twine/the-longarm.html in a browser to play, and import it into Twine once yourself (Library → Import).

Watch for

  • Lost work: browser Twine saves to that one browser. Say “Publish to File” early and often.
  • Orphan cards nothing links to. Ask: can a reader reach this?
  • Link typos make new empty passages. Spot the dashed-outline passages on the map.
  • Too many tiny branches: “Fewer, bigger choices.”

Act II · Patterns · Tracery

EmilyTextile · 25 min (step 5 only if time) · act2-tracery.html

They leave with: their own Tracery grammar, plus a flat version saved as grammar.json for Act IV.

Before

  • The playground on the act page runs offline. Load starter, quilt blocks, and cryptex (flat) once to check.
  • Kate Compton's Tracery tutorial open in a tab to point people to.
  • files/tracery/generator.html open in a tab for the “put it somewhere” step.

Watch for

  • JSON errors: curly quotes from a word processor, a missing comma, or a comma after the last item. Most “it broke” moments are one of these.
  • ((symbol)) in the output means a #symbol# with no rule; check spelling.
  • One word showing up too often: it's in many lists, or its list is short.
  • Flat grammar: every list the same length, plain words only, no #rules# inside.

Unmake (pick one)

  • Re:Traced Threads: a bot proposed quilted text and a person stitched it. Whose work is it? Who goes on the label?
  • When Twitter shut its API, Tracery bots moved because the format was open. What in your grammar would survive the next platform closing?

“Every block is a rule. A printed ring can't expand a rule, so for Act IV every word on one ring has to work next to every word on the others.”

Check before moving on: everyone has grammar.json saved somewhere they can find it. Hand to Anastasia for the intermission.

Intermission · Demo: Claude Code as power tool

AnastasiaBetween Acts II and III · 10 min, then it runs on its own

The point: show the power tool at full speed. We build something complicated together, then let it finish on auto mode while the room keeps making. Act IV is the slow, approve-every-step version of the same tool.

Before

  • Pick the build and test the opening prompt the night before. Not linked on the workshop site.
  • A repository and a Claude Code session open on the projector machine, signed in.
  • Power and a machine that won't sleep for the next hour.

Watch for

  • Plan with the room in plan mode, then switch to auto mode and say so out loud.
  • Leave the session visible or minimized but running; don't close the laptop.
  • If it stalls or asks a question, note it for Act IV rather than fixing it live.

Act III · Sketches · p5.js

EmilyZine · 25 min · act3-p5.html

They leave with: a p5.js sketch running their grammar, with a credit comment at the top.

Before

  • Everyone signs in to openprocessing.org (free account) before the act starts; it needs Wi-Fi. Make one test sketch from first-sketch.js yourself.
  • Your printed cryptex and flower spinner to pass around in step 4.
  • A way to print saved stills and make buttons from them (printer, paper, button maker).

Watch for

  • Blank canvas: the first red line in OpenProcessing's console names the line number.
  • Pasting the grammar: it replaces the whole grammarSource = { … } object, braces included.
  • Edited but nothing changed: press ▶ again.
  • Paste the whole .js file over the starter code; in tracery-particles.js, Tracery is the long part at the bottom, so leave it there.

Unmake (pick one)

  • Flash ended and a generation's work went with it. What would it take for your sketch to run in twenty years?

“A p5.js sketch is a plain text file. You can read it, keep it, and open it in ten years without anyone's permission.”

Set up the turn: “These prints started as sketches like yours. Anastasia's going to show you how to get from the grammar to the object, with an agent, while keeping the decisions yours.” Hand to Anastasia for Agents.

Act IV · Agents · Claude Code + OpenSCAD

AnastasiaGame · 35 min · act4-agents.html

They leave with: a GitHub repository with their grammar, a 3D preview, a .scad print file, and a process log ending in a label they'd sign.

Before

  • Ask people to make a free GitHub account early; it's the slowest step.
  • Your own repository ready to demo, with CLAUDE.md in place and a session open in claude.ai/code.
  • files/p5/cryptex-3d.html open with the flat grammar loaded.
  • OpenSCAD installed on the demo machine if you'll show F5/F6.

Watch for

  • Mode: auto mode has been the default since August. Have everyone switch to approving each step, and plan mode for the first two prompts.
  • No subscription: use the free chat route on the page (paste, copy files, upload by hand).
  • The agent “fixing” their words: point to the house rule “My words are mine.”
  • Pages not showing: Settings → Pages → main branch; give it a minute.
