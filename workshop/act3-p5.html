Sketches

p5.js is a JavaScript library for drawing, animation, and interaction on the web. Write a few lines, reload, change one thing, reload again. Then put your grammar inside a sketch.

5 min

1. A first sketch

Pick one place to work:

  • Offline, from this folder: open first-sketch.html in your browser and in a text editor. Edit, save, reload.
  • The p5.js web editor: editor.p5js.org. Paste in everything between the <script> tags.
  • OpenProcessing: openprocessing.org lets you fork someone's sketch with one click. Start with the course samples: bar chart, pie chart, text click.
10 min

2. setup() and draw()

Every p5.js sketch has two main functions. setup() runs once. draw() runs about sixty times a second. Event functions such as mouseClicked() run when something happens.

function setup() {
  createCanvas(windowWidth, windowHeight);
  background('#efe4cf');
}

function draw() {
  if (mouseIsPressed) {
    stroke('#7b4fb3');
    strokeWeight(6);
    line(pmouseX, pmouseY, mouseX, mouseY);   // from last frame's mouse to this one
  }
}

function mouseClicked() {
  fill(random(['#c0544a', '#3f8f8a', '#e2b33c']));
  rect(mouseX - 20, mouseY - 20, 40, 40);
}

In first-sketch.html, every line marked TRY is a place to change one thing. Change the colours, swap rect for ellipse, make every stamp the same size. Press S to save the canvas as an image.

Breaking it is part of the exercise. If the page goes blank, open the browser console (F12, or Cmd+Option+J on a Mac) and read the first red line. It usually names the line number.

10 min

3. Add your grammar

Open tracery-particles.html. Every click flattens a Tracery grammar into a line of text that drifts and fades. Find grammarSource and paste your Act II grammar over it:

const grammarSource = { /* your grammar from Act II */ };

function setup() {
  createCanvas(windowWidth, windowHeight);
  grammar = tracery.createGrammar(grammarSource);
  grammar.addModifiers(tracery.baseEngModifiers);
}

function mouseClicked() {
  particles.push(new Particle(mouseX, mouseY, grammar.flatten('#origin#')));
}

Then try the TRY lines: longer trails, a different drift, your own colours.

10 min

4. A grammar you can spin

Open flower-spinner.html. Two rings of petals turn on their own. When they stop, the pointer reads one word from each ring, the way a two-symbol rule like "#outer# meets #inner#" would.

Change the words to two fields of your own, or two halves of your grammar. This is a prototype of a physical object: in Act IV you'll turn it, or the four-ring cryptex, into a 3D print. Notice what the screen version can do that the print can't, and the other way round.

5 min

5. Fork and credit

The particle sketch has a history: an example by Allison Parrish, adapted for a critical making course, adapted again here. Each version keeps the credit in a comment at the top. Do the same:

<!-- Grammar and words: (you).
     Particle code adapted from the ENG 6819 demo, after Allison Parrish.
     p5.js (LGPL 2.1) and Tracery (ISC) are open source. -->

A p5.js sketch is a plain text file. You can read it, keep it, and open it in ten years without anyone's permission.

Unmake

  • Flash let a generation of small makers publish to the web, and when it ended, a huge amount of their work was lost. What would it take for your sketch to still run in twenty years?
  • If you paste your sketch into an AI assistant and it rewrites it, is it still yours? What about the grammar inside it?
  • Try distant coding: open a sketch you didn't write, find one line you understand, change it, and see what happens. How much of the code do you need to read to change it with intention?
